# Smart Cart - Price Comparison Platform

Smart Cart is a professional price intelligence platform that helps users compare grocery prices across multiple quick commerce applications like Blinkit, Zepto, and Instamart.

## Features

- **Real-time Price Comparison**: Scrapes live prices from major platforms.
- **Estimated Prices**: Fallback mechanism for robust reliability.
- **Deep Linking**: Direct links to mobile apps for seamless user experience.
- **Modern UI**: Clean, responsive interface for comparing deals.

## Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:

```bash
python run.py
```

Visit `http://localhost:5000` in your browser.
